# 每个文件干什么

把整个 `probe-gate` 文件夹拷到服务器即可。真人浏览器看不到弹窗。

| 文件 | 作用 |
| --- | --- |
| `server/classify.mjs` | 判定：爬虫 / 无头 / 机房 IP → 弹窗；真人 → 不弹 |
| `server/track.mjs` | 把核验、关弹窗写成日志，给后台统计 |
| `server/index.mjs` | HTTP 服务：接口 + 静态文件 |
| `public/probe.js` | 给目标网站嵌入的一行脚本（含弹窗 UI） |
| `public/admin.html` | 刷量检测后台页面 |
| `public/demo.html` | 本地看效果用 |
| `Dockerfile` / `docker-compose.yml` | 一键容器部署 |
| `README.md` | 部署步骤 |

挂站时只要：

```html
<script src="https://你的弹窗域名/probe.js"></script>
```
