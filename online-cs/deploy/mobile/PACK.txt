用 Git 环境打包 0199 App

在 Cursor / 本机已装 Android SDK 的环境里，从仓库源码重打 APK + 源码 zip：

  export ANDROID_HOME=/tmp/android-sdk   # 或你的 SDK 路径
  bash online-cs/deploy/mobile/scripts/env-pack.sh

仅打源码归档（不编译）：

  bash online-cs/deploy/mobile/scripts/git-pack.sh

产物目录：online-cs/deploy/mobile/dist/

- Android：app0199-release.apk 、 seat0199-release.apk
- 源码：mobile-0199-all.zip 、 *-android-src.zip 、 *-ios-src.zip
- iOS IPA：用 GitHub Actions（见 ios/GITHUB-IPA.md）或本机 Mac + Xcode；Linux 打不出已签名 IPA
