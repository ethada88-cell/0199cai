# 流量检测

一段放到其他网站上的脚本。管理账号可以开通别人的账号，并在刷量检测里查看全部账号的假量。普通账号只能看到自己的记录，脚本和数据不会串到其他账号。

访客先打开网站。脚本等页面出来后再在后台判断，不挡原来的页面打开。没有怀疑的访问不弹窗，直接计入真实 IP。没有广告来路（空来路、直达、站内跳转）一律记真实。群控/仿真人（硬环境、换机农场、确认差信誉 bad_* 等）在有广告来路时必弹窗验证，不能靠正常浏览直接洗白；学习灰信号 watch_* 不进群控。其余软特征看互动：有正常下拉/浏览改记真实；脚本态判定假量；无操作或仅轻触继续记嫌疑。虚拟显卡、爬虫、无头、自动化、模拟器、云手机，或两类互不重复的软特征，也判定假量。只要判定假量就弹窗滑动：滑到头改记真实；没有通过才记假量。自我学习账本约 7 天衰减一半。检测失败也直接放行。

后台是 `https://llcj.mtekww.cn/login`。脚本在登录后的账号页复制。

## 新服务器部署（不影响现网）

发布包与步骤见 [`deploy/DEPLOY.md`](deploy/DEPLOY.md)。在本机执行：

```bash
./deploy/pack.sh /tmp
# 得到 /tmp/traffic-guard-deploy-*.tar.gz ，拷到新机器解压后按 DEPLOY.md 启动
```

## 本地运行

```bash
npm install
npm run dev -- --hostname 0.0.0.0 --port 43127
```

后台要先登录。第一个管理账号、密码和会话密钥放在服务器的 `.env` 里（`ADMIN_USER`、`ADMIN_PASSWORD`、`ADMIN_SESSION_SECRET`），不要写进仓库。第一次打开后台时会用这组信息生成管理账号。之后在账号页改密码、开通别人的账号。未登录时打不开 `/admin`。检测失败或脚本里没有账号编号时，页面直接放行。

## 嵌到其他网站

在账号页复制代码。同一个账号的网站贴同一段，里面的 `data-account` 就是这个账号的编号：

```html
<script async src="https://llcj.mtekww.cn/guard.js" data-account="账号编号"></script>
```

脚本带 `async`，不写页面、不等检测结果：站点先照常打开。`guard.js` 进站约 2 秒后拉 `guard-run.js` 并执行检测。首次检测不弹窗，只有二次确认假量才盖页。失败了也不挡网站。人在这之前就离开，只补发一条不占页面的上报。网站域名由浏览器自己的来源确定。别的账号即使写同一个域名，记录也落在自己的编号下面，不能读到别人的数据。

住宅代理、同一台设备和共用出口来自同一类出口或指纹证据，只算一类。隐藏窗口、秒退、机房或代理地址各算一类。同一类里中了两条，仍然只是嫌疑。虚拟显卡单独出现就弹窗。两类同时出现，或者已经是换址进站（同一机型对得上，又换了很多地址、进了很多站，而且当前是机房或代理），才弹窗并可以记假量。滑到头的 IP 计入真实 IP。Cloudflare、Fastly 不单独当代理。内网地址不当机房。iPhone 报成 MacIntel、鸿蒙和国产浏览器报成电脑平台，不算模拟器。

## 后台里有什么

- 真实 IP、IP假量、PV假量、嫌疑 IP、嫌疑 PV、弹窗未通过、机房 IP、爬虫、滑动成功。各站点列表同样有这些数。IP 在每个站内去重，总览再把各站相加；同一 IP 去了多个站，总览里会加多次。嫌疑是软特征且无正常浏览，计入真实 IP，可点进看来路 / IP / 设备；有正常浏览改真实，脚本态弹窗（滑过=真实，不滑=假量）；学习账本衰减，常滑过来路会降权
- 来路分类，全部站点时能看到是哪个域名

假量只对准广告商外部来路刷量：广告商给网站带量时，用机房、代理、自动化等手段冲高访问，再按量收取更高费用。后台按外部来路域名归类这些假量，方便对渠道。

真实访问不出现在假量数字和来路表里。真实 IP 计入没弹窗的访问和滑动成功，同一个 IP 只算一次。真实 PV 计入每一次正常打开和每一次滑动成功。没有外部广告来路的访问——收藏夹、直达、站内跳转——记真实 IP 和真实 PV，不计假量，也不进来路明细。

地址表在 `data/ip-ranges.json`，可用 `node scripts/build-ranges.mjs` 重新生成（需要事先放好来源文件）。
